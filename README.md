# Thai Drive Secure Hub (Public Portal)

**Thai Drive Secure Hub** is a premium, user-centric web portal designed for Malaysian travelers driving into Thailand. It provides a seamless experience for comparing vehicle insurance plans, understanding border requirements, and initiating insurance applications with professional assistance from CNT Enterprise (Trusted since 1984).

## 🌟 Key Features

*   **Interactive Insurance Comparison**: Easily compare Compulsory (TPBI), Voluntary, and Voluntary Plus packages with detailed coverage breakdowns.
*   **Border Crossing Guide**: A step-by-step visual guide to navigating Malaysia–Thailand border checkpoints (Immigration, Customs, and Insurance verification).
*   **Document Checklist**: Interactive checklist for required vehicle (Grant/Road Tax) and personal documents to ensure a smooth crossing.
*   **Multi-language Support**: Fully localized in **English** and **Bahasa Melayu** to serve a diverse traveler base.
*   **Staff-Assisted Applications**: Direct WhatsApp integration for fast, human-verified insurance processing and expert support.
*   **Premium UI/UX**: Built with a "mobile-first" approach using Shadcn UI and Tailwind CSS for a sleek, modern, and accessible experience.

## 🛠️ Technology Stack

*   **Framework**: [React 18](https://react.dev/) + [Vite](https://vitejs.dev/)
*   **Language**: [TypeScript](https://www.typescriptlang.org/)
*   **Styling**: [Tailwind CSS](https://tailwindcss.com/)
*   **UI Components**: [shadcn/ui](https://ui.shadcn.com/) (Radix UI)
*   **Routing**: [React Router v6](https://reactrouter.com/)
*   **Data Fetching**: [TanStack React Query](https://tanstack.com/query/latest)
*   **Icons**: [Lucide React](https://lucide.dev/)

## 📂 Project Structure

- `/src/pages`: Main public pages including Home, About, FAQ, Border Guide, and Documents.
- `/src/pages/services`: Deep dives into Compulsory, Voluntary, and Travel insurance products.
- `/src/components`: Reusable UI components including the Hero section, Insurance Cards, and Comparison Tables.
- `/src/contexts`: Global state management for multi-language support via `LanguageContext`.

## 🚀 Getting Started

1. **Clone the repository:**
   ```bash
   git clone https://github.com/intis2ar-ux/thaidrivesecure-Website.git
   ```
2. **Install dependencies:**
   ```bash
   npm install
   ```
3. **Run in development mode:**
   ```bash
   npm run dev
   ```
